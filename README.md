# U.S. Traffic Accidents Analysis (Power BI Project)

This project analyzes over 500,000 U.S. traffic accidents to identify key trends and safety insights using Power BI and Excel.

## Tools Used
Power BI, Excel, SQL (basic), Google Sheets

## Key Insights
- Accidents increase during fog/rain
- Evening hours show peak frequency
- Top 5 states with highest severity reports

## Skills Applied
Data Cleaning • Data Visualization • Dashboard Design • Storytelling with Data
