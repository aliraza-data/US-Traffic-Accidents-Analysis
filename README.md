# US Traffic Accidents Analysis

A data analytics project focused on exploring traffic accident patterns across the United States using Power BI, Excel, and SQL. This project analyzes large-scale accident data to uncover trends related to weather conditions, time of day, location, and accident severity, helping transform raw data into meaningful safety insights.

## Project Overview

Traffic accidents are a major public safety concern in the United States. This project aims to identify key patterns and trends in accident data to answer questions such as:

• When do most accidents occur?  
• How do weather conditions affect accident severity?  
• Which states and regions are more accident-prone?  
• What patterns can help improve road safety awareness?

Interactive dashboards and visualizations are created to clearly present these insights in an easy-to-understand manner.

## Dataset Description

The dataset used in this project is the **US Accidents Dataset**, a large-scale traffic accident dataset covering multiple U.S. states.

Dataset features include:

• Accident location (Latitude, Longitude, City, State)  
• Date and time details (Year, Month, Day, Hour)  
• Weather conditions at the time of accident  
• Accident severity levels  
• Road and traffic-related attributes

🔗 **Direct Dataset Link (Kaggle):**  
https://www.kaggle.com/datasets/sobhanmoosavi/us-accidents

>  Note: The raw dataset is not stored in this repository due to GitHub file size limitations. Please download the dataset directly from Kaggle using the link above.

## Tools and Technologies

• Power BI for interactive dashboards  
• Microsoft Excel for data cleaning and preparation  
• SQL for querying and summarizing data  
• Google Sheets for initial exploration

## Key Insights

Some key insights identified during the analysis include:

• Higher accident frequency during rain and fog conditions  
• Peak accident occurrences during evening hours  
• Certain states consistently reporting higher accident severity  
• Weather and visibility playing a critical role in accident risk

Detailed visual insights can be explored through the Power BI dashboard included in this repository.
